# Check the SurveyCTO API has been authorized and stored as `auth`

Check the SurveyCTO API has been authorized and stored as `auth`

## Usage

``` r
check_scto_api(.auth = auth)
```

## Arguments

- .auth:

  an authorization block from `{rsurveycto::scto_auth}`

## Value

boolean

## Examples

``` r
NULL
#> NULL
```
