# Get survey data

Get the survey responses for a specific survey form from SurveyCTO via
API. This form is a wrapper for
[`rsurveycto::scto_read()`](https://agency-fund.github.io/rsurveycto/reference/scto_read.html).

## Usage

``` r
scto_responses(.formid, .auth)
```

## Arguments

- .formid:

  a character string that identifies the SurveyCTO form

- .auth:

  an authorization block generated by
  [`rsurveycto::scto_auth()`](https://agency-fund.github.io/rsurveycto/reference/scto_auth.html)

## Value

A `data.frame` of survey responses with every column in character
format. As if it were loaded from CSV with
`read.csv(..., colClasses="")`.
