# Get survey forms

Get the survey form definition for a specific survey form from SurveyCTO
via API. This form is a wrapper for
[`rsurveycto::scto_get_form_definitions()`](https://agency-fund.github.io/rsurveycto/reference/scto_get_form_definitions.html).

## Usage

``` r
scto_form(.formid, .auth)
```

## Arguments

- .formid:

  a character string that identifies the SurveyCTO form

- .auth:

  an authorization block generated by
  [`rsurveycto::scto_auth()`](https://agency-fund.github.io/rsurveycto/reference/scto_auth.html)

## Value

A list object that corresponds to the sheets of survey form from
SurveyCTO, which are typically downloaded as XLSX files. Class
data.frame and data.table. The list has four elements: `settings`,
`choices`, `fields`, and `formulasConvertedToStaticValues`.
